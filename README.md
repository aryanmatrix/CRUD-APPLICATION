# University Management System

## Overview
The University Management System is a web application built using React. It provides a platform to manage various aspects of a university, including student management and other administrative tasks.

## Features
- **Student Management:** Add, view, and manage student details.
- **Responsive Design:** Optimized for various screen sizes.
- **Modular Components:** Clean and reusable React components.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/aryanmatrix/CRUD-APPLICATION.git
   ```
2. Navigate to the project directory:
   ```bash
   cd CRUD-APPLICATION
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage
1. Start the development server:
   ```bash
   npm start
   ```
2. Open your browser and navigate to:
   ```
   http://localhost:1234
   ```

## Scripts
- **`npm start`**: Starts the development server.
- **`npm run build`**: Builds the app for production.
- **`npm test`**: Runs the test suite.
